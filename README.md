# begonia-custom-build

GitHub Actions build workflow for **Redmi Note 8 Pro (Begonia / MT6785)**

## Features
- 🌿 **KernelSU-Next** (sidex15 legacy-susfs-v2)
- 🛡️ **SUSFS** support (CONFIG_KSU_SUSFS=y)
- 🔧 **crDroid Clang r547379** toolchain
- 📦 **AnyKernel3** zip output

## How to use
1. Go to **Actions** tab
2. Select **🔨 Build Begonia Kernel**
3. Click **Run workflow** → choose branch (ifteen / ourteen / osp-13)
4. Wait ~30-45 minutes → download the zip artifact
